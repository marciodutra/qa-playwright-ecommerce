# QA Playwright E-commerce

## Objetivo

Este projeto foi desenvolvido como solução para um desafio técnico de QA Pleno, contemplando automação de testes End-to-End (UI) e testes de API utilizando Playwright e TypeScript.

## Tecnologias

- Playwright
- TypeScript
- Axios
- Faker
- Dotenv
- Winston

## Arquitetura

O projeto utiliza:

- Page Object Model (POM)
- Components
- Services
- Factories
- Helpers
- Config centralizada

## Estrutura do Projeto

```text

├── src/

```
